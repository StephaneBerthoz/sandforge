# Plan 04-01: Zod bump + AIClient scaffolding + AnthropicAdapter (happy path)

**Requirements covered:** AI-01 partial (adapter shape, factory wiring, key path), AI-04 partial (Zod-validated response replaces regex extract — closes RT-#11).

## Goal

Lay the AI substrate: bump zod to the version the Anthropic SDK helpers require, pin the SDK at the verified beta, ship the `AIClient` interface + a working `AnthropicAdapter` happy path (no breaker yet, no toolRunner yet — just `messages.parse` with `zodOutputFormat`), and wire it through `services.ts` as a lazy factory. A vertical-slice test proves an end-to-end call from `services.aiClient().complete(...)` returns a Zod-validated payload.

## Context

CONTEXT decisions locked: factory + 1 adapter per provider, per-AI-request AbortController, per-provider state lives on the adapter. RESEARCH §"Recommended Approach" mandates the directory layout; RESEARCH Pitfall #1 makes the zod bump a HARD prerequisite (the SDK helpers `import * as z from 'zod/v4'` which does not exist before 3.25). RESEARCH Pitfall #6 mandates per-call `usage = { input, output, cacheRead, cacheCreate, total }`. The adapter constructor reads the API key via `services.storage.getSecret('sandforge.ai.anthropic.key')` lazily on first call — never `process.env`, never globalState (HARD-06 already shipped).

The existing `AIAssistant`, `ErrorResolver`, `NL2SOQL`, `AIPersonaManager`, `SchemaAdvisor`, `SmartActionAnalyzer`, `AnomalyDetector`, `PipelineGenerator` modules MUST keep their public APIs intact and their tests MUST stay green. This plan only adds new files; it does NOT touch the eight existing AI modules. Plan 04-03 (and beyond) replaces their internal `provider(prompt)` callsite with `aiClient.complete(...)` — out of scope here.

## Pitfalls mitigated (RESEARCH §"Common Pitfalls")

- **P-04.1 (Zod version mismatch)** — bump zod to ^3.25 in BOTH extension + shared `package.json` BEFORE writing any adapter code.
- **P-04.6 (Token-budget counter drifts)** — adapter exposes `usage = { input, output, cacheRead, cacheCreate, total }` from every call.
- **P-04.7 (API key leaks via err.message)** — adapter wraps SDK errors via `extractAndRedactErrorMessage(err)` before re-throw.

# Plan 04-02: Per-provider CircuitBreaker + AbortController + provider-status banner

**Requirements covered:** AI-01 full (circuit breaker on 529, distinguish 429 vs 529 in UI copy, AbortController wired to "Cancel" button).

## Goal

Make `AnthropicAdapter` resilient: a 529 storm trips a per-provider breaker that auto-resets after 5 min; a 429 surfaces with retry-after; cancelling one chat does not abort siblings; the user sees an honest provider-status banner that distinguishes overload (529) from rate-limit (429) from cancellation. Breaker + abort logic is local to the AnthropicAdapter instance — Plan 04-07 will give OpenAIAdapter / CustomAdapter their own breakers. The factory's per-provider memoisation (shipped in 04-01) keeps this state alive between calls.

## Context

CONTEXT decisions locked: per-provider breaker, per-AI-request AbortController, breaker config matches AI-01 ("3 consecutive 529 -> disable 5min"). RESEARCH §"Don't Hand-Roll" confirms reuse of `packages/extension/src/core/connection/CircuitBreaker.ts`. RESEARCH Pitfall #2: the SDK has NO `OverloadedError` class — detect via dual signal `err.status === 529 OR err.error?.error?.type === 'overloaded_error'`. RESEARCH Pitfall #3: per-AI-request controller is mandatory (mirror `SalesforceAdapter.withLimit`). FleetSummaryService backoff curve `60s -> 120 -> 240 -> 480 -> 600 cap` is the agent-discretion default for retry-after when the API does not provide one.

A read of `packages/extension/src/core/connection/CircuitBreaker.ts` confirms the API: `acquirePermit()`, `recordSuccess()`, `recordFailure()`, `state`, `trip()`, `reset()`, options `{ failureThreshold, resetTimeout, halfOpenRequests }`. The breaker emits `state-change` events that the adapter must subscribe to in order to publish `ai:provider:status` envelopes.

## Pitfalls mitigated (RESEARCH §"Common Pitfalls")

- **P-04.2 (529 detection without OverloadedError class)** — `classifyAnthropicError` uses dual signal.
- **P-04.3 (Cancel cascade across in-flight requests)** — per-AI-request controller, never adapter-level shared signal.

- `interface AIErrorVerdict { kind, shouldTripBreaker, shouldRetry, retryAfterMs?, userMessageKey, rawStatus? }`. `userMessageKey` is an i18n key like `'ai.error.overloaded'`.
- `function classifyAnthropicError(err: unknown): AIErrorVerdict` — branches:

3. Add `public readonly breakerEvents = new EventEmitter()` (typed) — emits `'state-change'` with `{ state, lastError?, cooldownEndsAt? }`. Subscribe to the underlying `breaker.on('state-change', ...)` and re-emit upward.
4. Add `private inFlight = new Set<AbortController>()` — registry of currently-running controllers (for `cancelAll()`).
5. Refactor `chat()`, `complete()`, `countTokens()` into a shared `private async runWithBreaker<T>(method, exec, externalSignal): Promise<T>` helper:
   - If breaker is open via `acquirePermit()`, throw `Error('AI provider circuit breaker open. Try again in ~5 min.')` — fast-fail (no SDK call).
   - Allocate `const ctrl = new AbortController()`. Add to `this.inFlight`.
   - If `externalSignal` provided: subscribe `externalSignal.addEventListener('abort', () => ctrl.abort(externalSignal.reason))` (one-way mirror so cancelling the caller's signal aborts ONLY this request — Pitfall #3).
   - Try: invoke `exec(ctrl.signal)`; on success call `this.breaker.recordSuccess()` and return.
   - Catch: classify the error via `classifyAnthropicError(err)`. If `verdict.shouldTripBreaker` call `recordFailure()`; else if NOT cancelled, call `recordSuccess()` (don't penalise on auth/badrequest/transient). Then rewrap and rethrow.
   - Finally: remove `ctrl` from `this.inFlight`, remove the listener.
6. Each public method becomes a thin wrapper that calls `runWithBreaker('chat', (signal) => client.messages.create(..., { signal }), opts.signal)`.
7. Add `public cancelAll(): number` — iterates `this.inFlight`, calls `.abort()` on each, returns count cancelled. Used by panel-close cleanup (Plan 04-05).
8. Add `public dispose(): void` (extend existing) — calls `cancelAll()`, removes breaker listeners, clears the Set.

`rewrap(err, verdict)`:
- If `verdict.kind === 'cancelled'`: rethrow the original `APIUserAbortError` (preserves identity per 04-01 contract).
- Else: build a new `Error` whose message starts with `[ai:${verdict.kind}]` followed by `extractAndRedactErrorMessage(err)`; attach `cause = err`; attach `aiErrorVerdict = verdict` for handler-side localised banner copy.

Telemetry: every `recordFailure` fires `this.telemetry?.addBreadcrumb({ category: 'ai', message: 'breaker_failure', data: { kind: verdict.kind, status: verdict.rawStatus } })`. Every `state-change` to `'open'` fires a `Logger.warn` event.

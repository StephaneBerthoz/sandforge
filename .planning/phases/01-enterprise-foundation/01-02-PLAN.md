# Plan 01-02: UX Polish -- Skeleton Screens, Keyboard Shortcuts, Notification Center

## Objective

Deliver three user-facing polish features: skeleton loading screens replacing all remaining spinners (POLISH-02), keyboard shortcuts for module navigation and actions (POLISH-03), and an enhanced notification center with filtering (POLISH-04). These are independent from the infrastructure plan and can be built in parallel.

## Context

**Skeleton screens (POLISH-02):**
- `Skeleton` component already exists at packages/webview/src/components/ui/Skeleton.tsx with text/rect/circle variants and sf-skeleton CSS animation.
- `Spinner` component exists at packages/webview/src/components/ui/Spinner.tsx -- used in MonitorPage, OrgHealthPanel, RefreshPanel, AIChatPanel.
- The task is to create composite skeleton components (SkeletonTable, SkeletonCard, SkeletonPanel) that compose the existing Skeleton primitive, then replace Spinner usage in loading states.
- Do NOT delete the Spinner component (it may still be needed for inline button states). Just replace page-level loading states.

**Keyboard shortcuts (POLISH-03):**
- `useGlobalShortcuts` hook already exists with G+key chord navigation (G+H=home, G+M=monitor, etc.).
- `KeyboardShortcuts.tsx` is a reference modal showing all shortcuts.
- Requirement: add Ctrl+1..6 for direct module navigation (1=Monitor, 2=Seed, 3=Sync, 4=Compare, 5=DataOps, 6=Automation), Ctrl+Enter to trigger execute action, Escape to close modal/wizard, Tab for wizard step navigation.
- Tab wizard navigation already works via native browser behavior -- verify it works with the Wizard component.
- The `CommandPalette` component uses Ctrl+K -- avoid conflicts.

**Notification center (POLISH-04):**
- `NotificationCenter` exists at packages/webview/src/layouts/NotificationCenter/NotificationCenter.tsx -- a slide-out panel showing all notifications as Toast cards.
- `useNotificationStore` has basic add/remove/markRead/clearAll.
- Requirement: add filter tabs by level (all/info/success/warning/error), date grouping (today/earlier), category field (sync/seed/monitor/system), search within notifications.
- Notifications already have `level`, `title`, `message`, `timestamp`, `read`, `actions`.

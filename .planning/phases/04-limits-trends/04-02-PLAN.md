# Plan 02: Real Timestamps in Trends + Historical CSV Export

## Objective

Replace the synthetic timestamp generation in TrendCharts with real timestamps from TrendStorage (TREND-01) and extend LimitExportButton to export historical trend data as a multi-row CSV with real timestamps (TREND-02). Plan 01 already added the `timestamps` field to TrendData and populates it from TrendStorage; this plan wires it through to the UI.

## Context

- **useMonitorPageData.ts** (lines 205-223) builds `trendSeries` by mapping `TrendData.sparklineData` values. Currently, each data point's timestamp is synthesized as `new Date(Date.now() - (length - 1 - i) * 15 * 60 * 1000).toISOString()` (line 219). After Plan 01, `TrendData.timestamps` is populated with real ISO strings from snapshot storage. This plan replaces the synthesis with real timestamps.
- **trendChartData** (lines 196-203) also synthesizes timestamps with `Date.now() - offset * 15min`. This must also switch to real timestamps.
- **TrendCharts.tsx** already consumes `TrendDataPoint.timestamp` (string) and formats it via `formatTime()`. No changes needed to TrendCharts itself --- the fix is in the data preparation in useMonitorPageData.
- **LimitExportButton.tsx** currently exports a single-row-per-limit CSV (current snapshot only). For TREND-02, a second export function `generateHistoricalCsv` must produce one row per limit per timestamp. The component needs a toggle or separate button to choose "Export Historical". The `trends` prop already provides `Record<string, TrendData>` which now includes `timestamps`.
- **buildChartPath** in TrendCharts.tsx (line 62) uses `i / (data.length - 1)` for x-positioning (evenly spaced). For real timestamps, the x-position should be proportional to actual time elapsed between first and last data point. This ensures non-uniform sampling intervals render correctly.
- All text must use `t('key', 'default')` i18n pattern.

1. In `LimitExportButton.tsx`, add a new exported function `generateHistoricalCsv`:
   ```typescript
   /**
    * Generates a CSV string with historical trend data rows.
    * One row per limit per timestamp.
    * @param trends - Trend data keyed by limit name (with timestamps and sparklineData).
    * @returns CSV content string with columns: Timestamp,Limit Name,Used %
    */
   export function generateHistoricalCsv(
     trends: Record<string, TrendData>,
   ): string {
     const header = 'Timestamp,Limit Name,Used %';
     const rows: string[] = [];
     for (const [limitName, td] of Object.entries(trends)) {
       if (!td.timestamps || td.timestamps.length === 0) continue;
       for (let i = 0; i < td.sparklineData.length; i++) {
         const ts = td.timestamps[i] ?? '';
         rows.push(`"${ts}","${limitName}",${td.sparklineData[i]}`);
       }
     }
     return [header, ...rows].join('\n');
   }
   ```

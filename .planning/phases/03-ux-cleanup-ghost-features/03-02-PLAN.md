# Plan 02: Module-Specific Empty States

## Objective

Add tailored first-launch empty states to the 5 modules that lack them (Forge, Monitor, DataOps, Automation, Autopilot). Each empty state has a module-specific icon, title, description, and CTA button that guides the user to the next action.

## Context

- EmptyState component exists with rich API: module, icon, title, description, actionLabel, onAction
- Research Pitfall 4: EmptyStateModule type must be extended to include 'forge' and 'autopilot'
- Research Pitfall 7: i18n keys needed in en + fr, with English placeholders in de/es/ja/pt-BR
- Existing pattern: guard at top of page component, check orgs.length === 0 or !selectedOrg
- Seed/Sync/Compare already have empty states to use as reference

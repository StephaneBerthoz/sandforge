# Plan 03: Accessibility (A11Y-01..07)

## Objective

Bring all Forge webview components to WCAG 2.1 AA compliance by adding proper ARIA semantics: tablist/tab/tabpanel roles on ForgeReview, aria-pressed on filter buttons, role="log" with aria-live on LogStream, radiogroup semantics with arrow-key navigation on depth chips, correct interactive role on LiveGraph, onChange on ProgressNode checkbox, and contrast fix on skipped status. All changes are in the webview package and are completely independent from backend plans.

## Context

- ForgeReview uses custom tab buttons (not Radix Tabs). Need manual ARIA attributes.
- LogStream has filter buttons in two places: internal filter bar (visible when `hideFilterBar` is false) and ForgeExecution's external filter bar. Both need aria-pressed.
- Depth chips in ForgeInput are currently plain buttons. The radiogroup pattern requires roving tabindex (only the selected chip gets tabIndex=0, others get -1) and ArrowLeft/ArrowRight key handlers.
- LiveGraph currently has `role="img"` on the container div (line 168). Since the graph has clickable nodes, zoom controls, and checkboxes, it must be `role="application"`.
- ProgressNode checkbox on line 128 uses `onClick={handleCheckboxChange}` with `readOnly`. Must switch to `onChange`. The handler must adapt from `React.MouseEvent` to `React.ChangeEvent<HTMLInputElement>` -- but since it only calls `e.stopPropagation()` and `onIncludeToggle`, the change is straightforward.
- ForgeNodeDetail skipped status: `text-gray-500` needs to become `text-gray-400` for contrast.
- All test files exist and must be extended with accessibility-specific assertions.

const handleDepthKeyDown = useCallback((e: React.KeyboardEvent, currentDepth: ForgeDepth) => {
  const idx = DEPTH_OPTIONS.indexOf(currentDepth);
  let nextIdx = idx;
  if (e.key === 'ArrowRight' || e.key === 'ArrowDown') {
    e.preventDefault();
    nextIdx = (idx + 1) % DEPTH_OPTIONS.length;
  } else if (e.key === 'ArrowLeft' || e.key === 'ArrowUp') {
    e.preventDefault();
    nextIdx = (idx - 1 + DEPTH_OPTIONS.length) % DEPTH_OPTIONS.length;
  }
  if (nextIdx !== idx) {
    setDepth(DEPTH_OPTIONS[nextIdx]);
    // Focus the new radio button
    const nextEl = document.querySelector(`[data-testid="forge-depth-${DEPTH_OPTIONS[nextIdx]}"]`) as HTMLElement;
    nextEl?.focus();
  }
}, [setDepth]);

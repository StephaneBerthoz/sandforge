# Plan 02: Handler Integration

## Objective

Wire the 4 robustness utilities (RetryableOperation, TimeoutManager, BulkApiExecutor, FieldTypeValidator) into SeedOpsHandler and SyncOpsHandler. Load configuration from ConfigStore.

## Context

- Plan 01 created standalone utilities, this plan integrates them
- Handlers already have batching loops that need to be wrapped with retry/timeout
- BulkApiExecutor replaces manual batching when record count > threshold
- FieldTypeValidator runs as pre-flight check before Sync CRUD
- Configuration loaded from ConfigStore with 'robustness' category

const validator = new FieldTypeValidator();

  this.deps.broker.postToWebview(buildResponse(this.deps, msg, 'sync:execute:response', {

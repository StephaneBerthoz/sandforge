# Plan 02: Dashboard Refresh UX

## Objective

Polish the Monitor dashboard refresh experience (MON-03). Add per-panel loading states, error recovery with retry, stale data warnings, partial refresh resilience, and connection loss detection.

## Context

- Current refresh: manual button + 30s auto-refresh, loading only on initial load
- useMonitorPageData.ts is the central data hook
- ErrorBanner component exists for error display
- Badge component for stale indicator
- Framer Motion already used for animations

```tsx
function PanelOverlay({ isRefreshing, children }: { isRefreshing: boolean; children: ReactNode }) {
  return (
    <div className="relative">
      {children}
      {isRefreshing && (
        <div className="absolute inset-0 bg-background/50 flex items-center justify-center z-10">
          <Spinner size="sm" />
        </div>
      )}
    </div>
  );
}
```

```tsx
)}
```

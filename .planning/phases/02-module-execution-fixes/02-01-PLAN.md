# Plan 01: buildResponse Migration for All Handlers

## Objective

Replace all 27 manual response message constructions across 7 handlers with `buildResponse()` from HandlerTypes.ts. This ensures every response carries correlationId for reliable request-response matching. Also create test files for the 5 handlers missing them.

## Context

- `buildResponse(deps, request, type, payload)` auto-copies `request.id` as `correlationId`
- Currently only AI handlers use it; all others construct responses manually
- 5 of 7 handlers have no test file (Seed, Monitor, Autopilot, Compare, Automation)
- Research identified Pitfall 4: AutopilotHandler needs typed error responses, not just notifications

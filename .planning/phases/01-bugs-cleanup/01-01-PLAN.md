# Plan 01-01: Critical Bugs — Abort/Pause Wiring, dryRun Flag, Dynamic ID Prefix Resolution

## Context

Four bugs prevent core Forge functionality from working:

1. **BUG-01 + BUG-02** (tightly coupled): The abort signal is created in ForgeHandler but never reaches ForgeExecutor. Similarly, pause/resume only set a local boolean on ForgeHandler without calling ForgeExecutor's methods. ForgeExecutor already has correct pause/resume/abort implementation (Promise-based waiting at lines 90-124). The fix is to add forwarding methods on ForgeOrchestrator and wire ForgeHandler to call them.

2. **BUG-03**: The `SeedExecuteRequest` message type declares `dryRun: boolean` in payload, but `SeedOpsHandler.handleExecute` ignores it. The handler always performs real inserts regardless.

3. **BUG-06**: `GraphDiscoveryService.resolveObjectFromId()` uses a static `ID_PREFIX_MAP` with only 10 entries. Custom objects and many standard objects return "Unknown". The fix is to use `describeGlobal()` (already used in `ForgeHandler.handleForgePreview`) to resolve the prefix dynamically.

**Key patterns to follow:**
- ForgeExecutor already has working `abort()`, `pause()`, `resume()` methods
- `buildResponse(this.deps, msg, ...)` for all handler responses
- `GraphDiscoveryDeps` interface for dependency injection
- `resolveRootObject` must become async (currently sync) to support the API call

## Must-Haves

- [ ] MH-1: ForgeOrchestrator exposes `abort()`, `pause()`, `resume()` methods that delegate to `this.deps.executor`
- [ ] MH-2: ForgeHandler.handleAbort calls `this.orchestrator.abort()`, handlePause calls `this.orchestrator.pause()`, handleResume calls `this.orchestrator.resume()`
- [ ] MH-3: SeedOpsHandler.handleExecute extracts `dryRun` from payload and returns synthetic result (zero inserts) when `dryRun === true`
- [ ] MH-4: GraphDiscoveryService uses `describeGlobal` via deps instead of static `ID_PREFIX_MAP` for record ID prefix resolution
- [ ] MH-5: All existing tests pass plus new tests cover each fix
- [ ] MH-6: `pnpm typecheck` passes, `pnpm lint:fix` passes

   - `pause(): void` -- calls `this.deps.executor.pause()`

   - The `isPaused` property on ForgeHandler can be removed if it is not consumed elsewhere. Check for references before removing.

3. Add/update tests:
   - In `ForgeOrchestrator.test.ts`: Add tests verifying that `abort()`, `pause()`, `resume()` delegate to the executor mock.

     ```typescript

     ```

     ```typescript

     }
     ```
   - Place this branch AFTER the production guard check (if one exists) but BEFORE the actual insert logic.

2. Add tests in `SeedOpsHandler.test.ts`:
   - Test that when `dryRun: true` is in the payload, no records are inserted and response has `dryRun: true`.
   - Test that when `dryRun: false` (or absent), the normal insert path executes.

### Task 3: Replace static ID prefix map with describeGlobal (BUG-06)

**Files:**
- `packages/extension/src/modules/forge/GraphDiscoveryService.ts`
- `packages/extension/src/modules/forge/GraphDiscoveryService.test.ts`

**Action:**

1. In `GraphDiscoveryService.ts`:
   - Add a new dependency to `GraphDiscoveryDeps`:
     ```typescript
     describeGlobal: (orgId: string) => Promise<Array<{ name: string; keyPrefix: string | null }>>;
     ```
   - Delete the `ID_PREFIX_MAP` constant (lines 292-303) and the `resolveObjectFromId` function (lines 309-312).
   - Make `resolveRootObject` async (it is currently sync). Update its signature to `private async resolveRootObject(config: ForgeConfig): Promise<string>`.
   - In the `record` branch of `resolveRootObject`, replace the call to `resolveObjectFromId(config.recordId)` with:
     ```typescript
     const prefix = config.recordId!.substring(0, 3);
     const globalDesc = await this.deps.describeGlobal(config.sourceOrgId);
     const match = globalDesc.find(s => s.keyPrefix === prefix);
     if (!match) {
       throw new Error(`No object found for record ID prefix "${prefix}". The ID may not belong to any accessible object in this org.`);
     }
     return match.name;
     ```
   - Update the caller of `resolveRootObject` in the `discover` method to `await` it (it was previously sync).

2. Update `GraphDiscoveryService.test.ts`:
   - Add `describeGlobal` to the mock deps, returning a mock array of `{ name, keyPrefix }`.
   - Add a test that verifies `discover` with `inputMode: 'record'` calls `describeGlobal` and resolves the correct object.
   - Add a test that verifies an error is thrown when the prefix is not found.
   - Ensure existing SOQL-mode tests still pass (SOQL path is unaffected).

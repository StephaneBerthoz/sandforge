# Plan 01-02: Medium Bugs — Grappe Hero, Checkbox Visibility, Record ID, KPI Fix, i18n Key

## Context

Five UI-layer bugs that are all independent, surgical fixes (1-5 lines each). These can be done in parallel with Plan 01-01 (backend critical bugs) since they touch entirely different files.

1. **BUG-04**: SidePanel.tsx renders a Grappe hero button (lines 291-317) that navigates to a non-existent 'grappe' route. This must be removed entirely.

2. **BUG-05**: LiveGraph passes `onIncludeToggle` to ProgressNode, but during execution (ForgeExecution.tsx) and discovery (ForgeDiscovery.tsx), no callback is provided. ProgressNode renders a non-functional checkbox. The checkbox should be hidden when no callback is provided.

3. **BUG-07**: ForgeInput.tsx `handleDiscover` sends `recordId.trim()` raw to the backend config. If the user pasted a full Salesforce URL, the backend receives the URL instead of the 15/18-char ID. The `extractRecordId()` utility exists in the same file and is already used for preview -- it must also be used for config building.

4. **BUG-08**: ForgeResults.tsx has `const idRemaps = useMemo(() => inserted, [inserted])` -- always equals total inserted count. Should read `result?.idRemapCount ?? 0`.

5. **BUG-09**: ForgeNodeDetail.tsx line 78 uses `t('common.object')` for field count display. The key `common.object` does not exist in en.json. Should use `forge.fields`. The key `forge.fields` also does not exist yet -- it must be added to the locale file(s).

**Key constraints:**
- The `Network` import in SidePanel.tsx may become unused after removing the Grappe hero -- clean it up
- ProgressNode checkbox visibility change must not break ForgeReview (which correctly passes onIncludeToggle)
- `canPreview` in ForgeInput.tsx is still used (line 290 for a button disabled state) -- do NOT remove it in this plan (that is CLN-04 in Plan 01-03)

## Must-Haves

- [ ] MH-1: SidePanel no longer renders the Grappe hero button block (lines 291-317 removed)
- [ ] MH-2: ProgressNode hides the include checkbox when `onIncludeToggle` is not provided
- [ ] MH-3: ForgeInput.handleDiscover passes `extractRecordId(recordId)` (not `recordId.trim()`) to config
- [ ] MH-4: ForgeResults.idRemaps reads from `result?.idRemapCount ?? 0`
- [ ] MH-5: ForgeNodeDetail field count uses `t('forge.fields')` and the key exists in en.json
- [ ] MH-6: All existing tests pass plus new tests cover each fix
- [ ] MH-7: `pnpm typecheck` passes, `pnpm lint:fix` passes

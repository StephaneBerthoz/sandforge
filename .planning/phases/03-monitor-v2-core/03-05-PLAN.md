# Plan 03-05: AnomalyEngine — rolling 24h std-dev

**Requirements covered:** MON-05 (rolling-std-dev anomaly detection on time-series data; warmup-aware; bridge into existing AlertEngine).

## Goal

Ship AnomalyEngine — a pure-function rolling 24h std-dev anomaly detector that consumes TimeSeriesStore samples, gates emissions through a warmup state (30 samples + 6h span minimum), and surfaces anomalies in the existing AlertsPanel via synthetic AlertInstances (NOT new AlertDefinitions). Demoable via property tests proving warmup invariants + a vertical-slice test that pushes 100 monotone samples then 1 outlier and asserts exactly one `monitor:anomaly:detected` event with all RESEARCH §4 fields.

## Depends on

- **03-01** ships `MetricBus` + the `monitor:anomaly:detected` envelope shape with the exact fields needed for narration in Phase 04 (`{ orgId, seriesId, value, mean, stdDev, zScore, recentContext }`).
- **03-02** ships `TimeSeriesStore` — AnomalyEngine queries it for the 24h rolling window per `(orgId, seriesId)`.

No file overlap with sibling Wave 2 plans:
- **03-04** writes `DriftDetector.ts` + `DriftFeed.tsx` — disjoint.
- **03-06** writes `ReportExporter.ts` + uses pdfkit — disjoint.
- **03-07** writes `MonitorOverviewPage.tsx` — disjoint.

This plan touches `AlertEngine.ts` ONLY in a single-method add (the synthetic-AlertInstance bridge function); 03-04 / 03-06 / 03-07 do not touch `AlertEngine.ts`. No conflict.

## Non-goals

- **Replacing `AlertEngine`.** Per CONTEXT non-goal #1 + RESEARCH §2 ("AlertEngine — anomalies plug INTO it"). Anomalies create `AlertInstance` shapes via a thin bridging function — they do NOT pollute `AlertEngine.definitionStore` with synthetic `AlertDefinition` entries.
- **A settings slider for σ tuning.** CONTEXT D-03-5 + Open Question Q3 — defer to v1.4. Ship `3σ` as the only public threshold for v1.3.0.
- **Adding `simple-statistics` / `mathjs` / `d3-array`.** RESEARCH §1 forbids — math is < 50 LOC pure.
- **Time-series forecasting / linear regression.** GovernorLimitPredictor already does linear regression; AnomalyEngine is purely the per-sample baseline-deviation detector.
- **Coupling AnomalyEngine to AlertEngine internals beyond a public `submitInstance()` method.** Bridging is one-directional and minimal.
- **Writing anomaly events to disk.** Anomaly state is derived (TimeSeriesStore samples are the source of truth) — AnomalyEngine has no persistence.

## Pitfalls mitigated (RESEARCH §3)

- **P-03.3 (False positives at startup)** — warmup gate, sigma scale-up at low n, persistence-aware rehydration via TimeSeriesStore (Plan 03-02 already opt-in persistence rehydrates samples), telemetry breadcrumb on suppression.
- **P-03.8 (Discriminated-union exhaustiveness)** — AnomalyDetectedEvent already in the union per Plan 03-01.

```typescript
import type { MetricSample } from '@sandforge/shared';

/** Constants exported for tests + AnomalyEngine. */
export const MIN_SAMPLES_FOR_BASELINE = 30;
export const MIN_BASELINE_SPAN_MS = 6 * 60 * 60 * 1000;          // 6h
export const DEFAULT_WINDOW_MS = 24 * 60 * 60 * 1000;            // 24h
export const DEFAULT_SIGMA_THRESHOLD = 3;

/** Filter samples to those within [now - windowMs, now]. */
export function windowOf(samples: MetricSample[], now: number, windowMs = DEFAULT_WINDOW_MS): MetricSample[] {
  const cutoff = now - windowMs;
  return samples.filter((s) => new Date(s.ts).getTime() >= cutoff);
}

/** Mean of sample values; NaN-safe (returns 0 on empty). */
export function rollingMean(samples: MetricSample[]): number {
  if (samples.length === 0) return 0;
  let sum = 0;
  for (const s of samples) sum += s.value;
  return sum / samples.length;
}

/** Population std-dev (Welford-equivalent two-pass). */
export function rollingStdDev(samples: MetricSample[], mean?: number): number {
  if (samples.length < 2) return 0;
  const m = mean ?? rollingMean(samples);
  let acc = 0;
  for (const s of samples) acc += (s.value - m) ** 2;
  return Math.sqrt(acc / samples.length);
}

/** zScore. Returns 0 if stdDev is 0 (degenerate / constant series). */
export function zScore(value: number, mean: number, stdDev: number): number {
  if (stdDev === 0) return 0;
  return (value - mean) / stdDev;
}

/** Small-sample threshold widening: scale 3σ by (1 + 1/sqrt(n)) for n < 100 (P-03.3). */
export function effectiveThreshold(baseSigma: number, n: number): number {
  if (n >= 100) return baseSigma;
  return baseSigma * (1 + 1 / Math.sqrt(Math.max(n, 1)));
}

/** Returns true iff samples meet warmup criteria (P-03.3). */
export function isWarmedUp(samples: MetricSample[]): boolean {
  if (samples.length < MIN_SAMPLES_FOR_BASELINE) return false;
  const oldest = new Date(samples[0].ts).getTime();
  const newest = new Date(samples[samples.length - 1].ts).getTime();
  return (newest - oldest) >= MIN_BASELINE_SPAN_MS;
}
```

Tests in `anomaly-math.test.ts`:
1. `rollingMean` of 1 sample = its value.
2. `rollingMean` of empty array = 0.
3. `rollingStdDev` of constant samples = 0.
4. `rollingStdDev` of [1,2,3,4,5] mean=3 → sqrt(2) ≈ 1.414.
5. `zScore` of value=mean returns 0.
6. `zScore` with stdDev=0 returns 0 (no division by zero).
7. `effectiveThreshold(3, 200)` = 3 (n ≥ 100).
8. `effectiveThreshold(3, 9)` = 3 * (1 + 1/3) = 4.
9. `isWarmedUp([])` = false; `isWarmedUp(29 samples)` = false (under MIN_SAMPLES); `isWarmedUp(30 samples spanning 5h)` = false (under MIN_SPAN); `isWarmedUp(30 samples spanning 6h)` = true.

```typescript
import type { MetricSample } from '@sandforge/shared';
import type { MetricBus } from './MetricBus';
import type { TimeSeriesStore } from './TimeSeriesStore';
import type { Logger, TelemetryService } from '../../core/types';
import {
  windowOf, rollingMean, rollingStdDev, zScore, effectiveThreshold, isWarmedUp,
  MIN_SAMPLES_FOR_BASELINE, DEFAULT_WINDOW_MS, DEFAULT_SIGMA_THRESHOLD,
} from './anomaly-math';

export interface AnomalyEngineDeps {
  metricBus: MetricBus;
  timeSeriesStore: TimeSeriesStore;
  logger?: Logger;
  telemetry?: TelemetryService;
  windowMs?: number;
  sigmaThreshold?: number;
  now?: () => number;
}

export interface AnomalyDetectedEvent {
  orgId: string;
  seriesId: string;
  value: number;
  mean: number;
  stdDev: number;
  zScore: number;
  recentContext: MetricSample[];     // last 10 samples — for AI narration in Phase 04
  detectedAt: string;                 // ISO
}

export class AnomalyEngine {
  private windowMs: number;
  private sigmaThreshold: number;
  private suppressionLog = new Map<string, number>();   // (orgId,seriesId) -> last-suppression-ts
  private subscriberUnsub?: () => void;

  constructor(private deps: AnomalyEngineDeps) {
    this.windowMs = deps.windowMs ?? DEFAULT_WINDOW_MS;
    this.sigmaThreshold = deps.sigmaThreshold ?? DEFAULT_SIGMA_THRESHOLD;
  }

  /** Wire up: subscribe to monitor:metric events; for each, evaluate. */
  start(): void {
    this.subscriberUnsub = this.deps.metricBus.subscribe('monitor:metric', (sample) => this.evaluate(sample));
  }

  /** Public for tests. */
  evaluate(sample: MetricSample): AnomalyDetectedEvent | null {
    const now = this.deps.now?.() ?? Date.now();
    const window = windowOf(
      this.deps.timeSeriesStore.query(sample.orgId, sample.seriesId, now - this.windowMs, now),
      now,
      this.windowMs,
    );
    // Exclude the just-recorded sample from the baseline (anomaly is OUTSIDE the baseline)
    const baseline = window.slice(0, window.length - 1);
    const seriesKey = `${sample.orgId}:${sample.seriesId}`;

    if (!isWarmedUp(baseline)) {
      const lastSuppression = this.suppressionLog.get(seriesKey) ?? 0;
      if (now - lastSuppression > 60 * 60 * 1000) {     // log at most once per hour per series
        this.deps.telemetry?.addBreadcrumb({
          category: 'monitor', message: 'anomaly-suppressed-warmup',
          data: { orgId: sample.orgId, seriesId: sample.seriesId, baselineLen: baseline.length },
        });
        this.suppressionLog.set(seriesKey, now);
      }
      return null;
    }

    const mean = rollingMean(baseline);
    const stdDev = rollingStdDev(baseline, mean);
    if (stdDev === 0) return null;     // constant series — no signal
    const z = zScore(sample.value, mean, stdDev);
    const threshold = effectiveThreshold(this.sigmaThreshold, baseline.length);

    if (Math.abs(z) < threshold) return null;

    const event: AnomalyDetectedEvent = {
      orgId: sample.orgId,
      seriesId: sample.seriesId,
      value: sample.value,
      mean, stdDev, zScore: z,
      recentContext: baseline.slice(-10),
      detectedAt: new Date(now).toISOString(),
    };
    this.deps.metricBus.emit('monitor:anomaly:detected', event as any);   // Plan 03-01 envelope shape
    return event;
  }

  dispose(): void {
    this.subscriberUnsub?.();
    this.subscriberUnsub = undefined;
    this.suppressionLog.clear();
  }
}
```

it('Plan 03-05 vertical slice: 100 monotone samples + 5σ outlier emits exactly 1 anomaly + bridges to AlertEngine', () => {
  const bus = new MetricBus();
  const store = new TimeSeriesStore();
  const alertEngine = new AlertEngine();
  const anomalies: AnomalyDetectedEvent[] = [];
  const alertInstances: AlertInstance[] = [];

  bus.subscribe('monitor:anomaly:detected', (ev) => anomalies.push(ev));

  const engine = new AnomalyEngine({ metricBus: bus, timeSeriesStore: store });
  engine.start();

  // 100 baseline samples spanning 24h, mean ≈ 50, stdDev ≈ 5 (pseudo-random Gaussian-ish)
  const dayStart = Date.now() - 24 * 60 * 60 * 1000;
  for (let i = 0; i < 100; i++) {
    const sample = {
      ts: new Date(dayStart + i * (24 * 60 * 60 * 1000) / 100).toISOString(),
      orgId: 'org-1',
      seriesId: 'limits.api',
      value: 50 + Math.sin(i / 7) * 5,    // bounded around 50, std-dev ~3.5

    store.record(sample, { intervalMs: 30_000 });
    bus.emit('monitor:metric', sample);

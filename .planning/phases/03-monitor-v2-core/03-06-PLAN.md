# Plan 03-06: ReportExporter — PDF (pdfkit) + CSV (hand-rolled)

**Requirements covered:** MON-06 (PDF + CSV report export for any dashboard view).

## Goal

Ship ReportExporter that takes a `DashboardView` descriptor + time range, queries TimeSeriesStore, and renders to (a) hand-rolled CSV in the extension and (b) PDF via lazy-imported `pdfkit` with inline-SVG sparklines and LTTB downsampling. Demoable: a unit test that exports a 1000-sample × 5-series fixture to a tmp file path and asserts file size + magic bytes (`%PDF-` for PDF, `seriesId,...` header for CSV).

## Depends on

- **03-02** ships `TimeSeriesStore` — `ReportExporter` queries it for sample data per `(orgId, seriesId, fromMs, toMs)`.

NO direct dependency on Plan 03-01 (MetricBus) — exporter is a request-response handler, not a bus subscriber. NO direct dependency on 03-03 (Probes) — exporter doesn't run probes.

No file overlap with sibling Wave 2 plans:
- **03-04** writes Drift-related files in `compare/` + `webview/components/monitor/DriftFeed.tsx` — disjoint.
- **03-05** writes `AnomalyEngine.ts` + `anomaly-math.ts` — disjoint.
- **03-07** writes `MonitorOverviewPage.tsx` + `monitor:fleet:summary` handler — different bridge handler. Both 03-06 and 03-07 add to `messages.types.ts` + `messageSchemas.ts` (additive, different message types — `monitor:export:*` vs `monitor:fleet:*`); both add to `extension.ts` (additive handler registration). Append-only conflict-free.

## Non-goals

- **i18n PDF labels.** RESEARCH §7 explicitly defers — pdfkit ships with Helvetica only; embedding a Unicode font is a 250 KB hit. Phase 03 ships ENGLISH-ONLY PDF labels. CSV is locale-neutral (numeric + ISO timestamps). i18n PDFs deferred to v1.4.
- **WebView-side PDF (jsPDF).** RESEARCH §1 forbids — bridge envelope size limit + font rendering issues.
- **Chart libraries other than inline SVG sparklines.** RESEARCH §1 forbids `chartjs-node-canvas` (native binding hell).
- **Streaming CSV with papaparse.** RESEARCH §1 Option A — hand-rolled is < 15 LOC for our bounded data shape. Option B (papaparse) defers to v1.4 if any view exports > 50K rows.
- **HTML / Markdown export.** Out of scope — only CSV and PDF.
- **Email / cloud upload of exports.** Local file save only. The export `filePath` is the user's choice via VS Code's `vscode.window.showSaveDialog`.
- **Stryker re-baseline on ReportExporter.** Inherited threshold (Phase 02 P-02.1). Run incremental smoke only.

## Pitfalls mitigated (RESEARCH §3)

- **P-03.4 (PDF memory pressure on large ranges)** — stream-pipe to disk via `fs.createWriteStream`; cap series at 50 per PDF; downsample sparklines via LTTB to 800 points max; emit `monitor:export:progress` events.
- **P-03.10 (Persistence rehydration race)** — exporter only READS from TimeSeriesStore — read happens after rehydrate completes (Plan 03-02 wires that ordering).

## Open questions

- **CSV: hand-roll vs papaparse**. **Default chosen by this plan: HAND-ROLL** (RESEARCH §1 Option A) for v1.3.0. Re-evaluate in v1.4 if any view exports > 50K rows. (RESEARCH §1 explicitly defers this decision to plan-phase; we pick.)
- **PDF i18n**. **Default chosen: English-only PDF labels for v1.3.0** per RESEARCH §7 LOW confidence note. Localized PDFs deferred to v1.4 (requires embedding a Unicode font — 250 KB bundle hit not justified for v1.3.0).

```typescript
/**
 * RFC 4180 CSV escape: a value is wrapped in double quotes if it contains
 * comma, double-quote, or newline. Embedded double-quotes are doubled.
 */
export function escapeCsvField(value: unknown): string {
  if (value === null || value === undefined) return '';
  const str = String(value);
  if (str.includes('"') || str.includes(',') || str.includes('\n') || str.includes('\r')) {
    return `"${str.replace(/"/g, '""')}"`;
  }
  return str;
}

export function rowToCsv(row: readonly unknown[]): string {
  return row.map(escapeCsvField).join(',');
}

export function rowsToCsv(rows: readonly (readonly unknown[])[]): string {
  return rows.map(rowToCsv).join('\r\n') + '\r\n';
}
```

```typescript
import type { MetricSample } from '@sandforge/shared';

export interface Point { x: number; y: number; }

/**
 * Largest-Triangle-Three-Buckets — well-known O(n) time-series downsampler.
 * Preserves visual fidelity of peaks/troughs at small bucket counts.
 *
 * @param data Input points (must be sorted by x).
 * @param threshold Target output length. If data.length <= threshold, returns input unchanged.
 */
export function lttb(data: readonly Point[], threshold: number): Point[] {
  if (threshold >= data.length || threshold === 0) return [...data];
  if (threshold < 3) return [data[0], data[data.length - 1]];

  const sampled: Point[] = [];
  const bucketSize = (data.length - 2) / (threshold - 2);
  let a = 0;
  sampled.push(data[a]);

  for (let i = 0; i < threshold - 2; i++) {
    const avgRangeStart = Math.floor((i + 1) * bucketSize) + 1;
    const avgRangeEnd = Math.min(Math.floor((i + 2) * bucketSize) + 1, data.length);
    let avgX = 0, avgY = 0;
    const avgRangeLen = avgRangeEnd - avgRangeStart;
    for (let j = avgRangeStart; j < avgRangeEnd; j++) { avgX += data[j].x; avgY += data[j].y; }
    avgX /= avgRangeLen; avgY /= avgRangeLen;

    const rangeOffs = Math.floor(i * bucketSize) + 1;
    const rangeTo = Math.floor((i + 1) * bucketSize) + 1;
    const pointAX = data[a].x;
    const pointAY = data[a].y;
    let maxArea = -1;
    let maxAreaPoint = data[rangeOffs];
    let nextA = rangeOffs;
    for (let j = rangeOffs; j < rangeTo; j++) {
      const area = Math.abs((pointAX - avgX) * (data[j].y - pointAY) - (pointAX - data[j].x) * (avgY - pointAY)) * 0.5;
      if (area > maxArea) { maxArea = area; maxAreaPoint = data[j]; nextA = j; }
    }
    sampled.push(maxAreaPoint);
    a = nextA;
  }
  sampled.push(data[data.length - 1]);
  return sampled;
}

export function samplesToPoints(samples: readonly MetricSample[]): Point[] {
  return samples.map((s) => ({ x: new Date(s.ts).getTime(), y: s.value }));
}
```

Tests in `lttb.test.ts` (≥ 5):
1. Threshold ≥ data length → returns input unchanged.
2. Threshold < 3 → returns [first, last].
3. Threshold = 100 against 10_000 input points → returns exactly 100 points.
4. First and last points preserved (visual continuity guarantee).
5. Constant-y series → all output points have the same y.
6. Property test (100 runs): for any sorted point array of length N ≥ 3 + threshold T (3 ≤ T ≤ N), output length === T AND output is sorted by x.

```typescript
private async writePdf(seriesData: Map<string, MetricSample[]>, filePath: string): Promise<number> {
  // P-03.4 cap: 50 series per PDF
  const MAX_SERIES_PER_PDF = 50;
  const SPARKLINE_POINTS = 800;

  const allSeries = [...seriesData.entries()];
  const partCount = Math.ceil(allSeries.length / MAX_SERIES_PER_PDF);
  let totalBytes = 0;

  for (let part = 0; part < partCount; part++) {
    const partFilePath = partCount === 1
      ? filePath
      : filePath.replace(/(\.pdf)$/i, `.part${part + 1}$1`);
    const partSeries = allSeries.slice(part * MAX_SERIES_PER_PDF, (part + 1) * MAX_SERIES_PER_PDF);
    totalBytes += await this.writePdfPart(partSeries, partFilePath, part + 1, partCount);
  }
  return totalBytes;
}

private async writePdfPart(
  series: [string, MetricSample[]][],
  filePath: string,
  partIndex: number,
  partCount: number,
): Promise<number> {
  // Lazy import — RESEARCH §1 + CONTEXT D-03-6
  const PDFDocument = (await import('pdfkit')).default;
  const doc = new PDFDocument({ size: 'A4', margin: 50, autoFirstPage: true });

  // P-03.4 stream-pipe to disk — pdfkit emits chunks as it writes; do NOT buffer in memory
  const stream = fs.createWriteStream(filePath);
  doc.pipe(stream);

  // Header
  doc.fontSize(18).text(`SandForge Monitor Report${partCount > 1 ? ` (Part ${partIndex} of ${partCount})` : ''}`, { align: 'left' });
  doc.fontSize(10).fillColor('#666').text(`Generated: ${new Date().toISOString()}`, { align: 'left' });
  doc.moveDown();

  // Per-series block
  for (const [seriesId, samples] of series) {
    if (samples.length === 0) continue;
    doc.fillColor('black').fontSize(12).text(seriesId, { continued: false });
    // Sparkline: downsample to 800 points then render as inline SVG
    const downsampled = lttb(samplesToPoints(samples), SPARKLINE_POINTS);
    const svg = this.buildSparklineSvg(downsampled);
    doc.svg(svg, { width: 480, height: 60 });    // pdfkit ≥ 0.13 has native .svg()
    // Mini stats
    const values = samples.map((s) => s.value);
    const min = Math.min(...values), max = Math.max(...values);
    const avg = values.reduce((a, b) => a + b, 0) / values.length;
    doc.fontSize(9).fillColor('#444')
       .text(`min: ${min.toFixed(2)}   avg: ${avg.toFixed(2)}   max: ${max.toFixed(2)}   n: ${samples.length}`);
    doc.moveDown();
  }

  if (partCount > 1 && partIndex < partCount) {
    doc.fontSize(9).fillColor('#aaa').text(`Continued in part ${partIndex + 1}`, { align: 'right' });
  }

  // P-03.4 — finalize
  doc.end();
  await new Promise<void>((resolve, reject) => {
    stream.on('finish', () => resolve());
    stream.on('error', reject);
  });
  const stat = await fs.promises.stat(filePath);
  return stat.size;
}

private buildSparklineSvg(points: Point[]): string {
  if (points.length === 0) return '<svg width="480" height="60"></svg>';
  const W = 480, H = 60, P = 4;
  const xs = points.map((p) => p.x);
  const ys = points.map((p) => p.y);
  const xMin = Math.min(...xs), xMax = Math.max(...xs);
  const yMin = Math.min(...ys), yMax = Math.max(...ys);
  const xRange = Math.max(xMax - xMin, 1);
  const yRange = Math.max(yMax - yMin, 1);
  const path = points
    .map((p) => {
      const x = P + ((p.x - xMin) / xRange) * (W - 2 * P);
      const y = H - P - ((p.y - yMin) / yRange) * (H - 2 * P);
      return `${x.toFixed(2)},${y.toFixed(2)}`;
    })
    .join(' ');
  return `<svg width="${W}" height="${H}" xmlns="http://www.w3.org/2000/svg"><polyline fill="none" stroke="#3b82f6" stroke-width="1" points="${path}"/></svg>`;
}
```

# Plan 01: buildResponse Migration for Infrastructure Handlers

## Objective

Replace all 36 manual response constructions in 6 infrastructure handlers with `buildResponse()` from HandlerTypes.ts. This completes BRG-02: every handler in the extension will propagate correlationId.

## Context

- buildResponse signature: `buildResponse<P>(deps, request, type, payload)` → returns `{ id, type, timestamp, correlationId: request.id, payload }`
- 10 domain handlers already migrated in Phase 2 (80 buildResponse calls)
- Pattern: replace `{ type: '...', id: this.deps.nextId(), timestamp: Date.now(), payload: ... }` with `buildResponse(this.deps, message, '...', { ... })`
- Error responses follow the same pattern: `buildResponse(this.deps, message, 'type:response', { success: false, error: '...' })`
- Import: `import { buildResponse } from './HandlerTypes.js';` (or `'../HandlerTypes.js'` for AI sub-handlers)

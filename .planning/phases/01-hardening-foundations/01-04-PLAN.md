# Plan 01-04: Bridge Hardening + Leak Audit

**Requirements covered:** HARD-05 (Zod validation for all WebView messages + `protocolVersion` envelope), HARD-07 (disposable hygiene audit + leak fix + 1h soak baseline)

**Goal:** (1) Add a Zod discriminated-union schema covering every bridge message type, parse every inbound message at `MessageRouter` boundary, add a `protocolVersion` envelope field, show a reload banner on mismatch. (2) Write a ts-morph script that audits `setInterval`/`setTimeout`/`EventEmitter.on`/`onDidChange*`/`onDidReceiveMessage` registrations for matching disposables. Fix identified leaks. (3) Add a soak-test harness that activates the extension, runs monitor cycles for 1h, captures RSS delta.

**Depends on:** Plan 01-01 (TelemetryAdapter for logging mismatch events).

**Non-goals:** Rewriting message types (only adding protocolVersion envelope); implementing MetricBus ring-buffer caps (Phase 03).

Own a single `pLimit(concurrency)` instance. Method `withLimit<T>(fn: () => Promise<T>, opts?: { signal?: AbortSignal; category?: string }): Promise<T>` that wraps `fn` in p-limit + p-retry. Method `shouldPauseNonEssential(): Promise<boolean>` — true if last `checkLimits()` pct > 0.8. Emit telemetry breadcrumb on every retry, every 429, and every pct > 0.8. Export via `adapters/salesforce/index.ts`. NOTE: this plan does NOT migrate existing jsforce callers — that's deferred to Plan 01-03.</action>
<verify>Class exported. `pnpm typecheck` green.</verify>

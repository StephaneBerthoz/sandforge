# Plan 01-03: DI Composition Root & Secret Migration

**Requirements covered:** HARD-02 (composition root + DI refactor), HARD-06 (SecretStorage migration runner completing Plan 01-01's StorageAdapter)

**Goal:** Ship `createServices(context)` in `services.ts` returning a typed `Services` object. Refactor `extension.ts::activate` to call it. Refactor 6 orchestrators to accept injected services via constructor. Add SecretStorage migration runner that silently moves known legacy globalState keys to SecretStorage on activation.

**Depends on:** Plan 01-01 (SalesforceAdapter, TelemetryAdapter, StorageAdapter, FsAdapter must exist and be exported from `adapters/`).

**Non-goals:** Migrating individual jsforce callers inside orchestrators (gradual per-module migration is a Phase 03/later concern — this plan only wires the adapter into the orchestrator constructor; internal method bodies still use jsforce directly for now). Touching MessageRouter/handlers Zod validation (that's Plan 01-04).

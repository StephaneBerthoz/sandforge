# Plan 02: Smart Action Recommender & Just Do It

## Objective

Build the Smart Action recommender that analyzes connected org state and surfaces a contextual recommendation on the HomePage. When the user opens the HomePage, the system queries record counts on 5 standard objects in the target org (and optionally the source org), determines the best action (Quick Seed for empty sandboxes, Clone if source has data and target is empty, Sync if both populated but target is stale), and displays a prominent recommendation card above the BentoGrid with a one-click Execute button. This card implements the "Just Do It" mode — confirmation before execution, then routes to the appropriate flow.

## Context

- **SmartSuggestions** (`packages/extension/src/modules/ai/SmartSuggestions.ts`) exists as a module-level rule engine. Smart Action is different — it's org-level analysis, not module-level. Create a new `SmartActionAnalyzer` class rather than extending SmartSuggestions.
- **jsforce queries**: Use `conn.query("SELECT COUNT() FROM Account")` which returns `{ totalSize: number }`. For 5 objects in parallel: `Promise.all(objects.map(obj => conn.query(...)))`. This takes ~1-2s total.
- **CacheManager** (`packages/extension/src/core/cache/CacheManager.ts`): Use it to cache record count results with 5-minute TTL (key: `smart-action:${orgId}`). Invalidated automatically on org switch via CacheManager's org-switch listener.
- **HomePage** (`packages/webview/src/pages/Home/HomePage.tsx`): BentoGrid starts at line 155. SmartActionCard goes ABOVE it, as a conditional block visible only when a recommendation exists. Use AnimatePresence for fade-in/fade-out.
- **useAppStore.navigate()**: Used to route to modules. After confirmation, route to `'seed'` (for Quick Seed), `'seed'` with clone mode (for Clone), or `'grappe'` (for Sync). Pass params via URL search params or a shared state.
- **Existing patterns**:
  - `useBridgeQuery` for fetching recommendation
  - `useBridgeMutation` for triggering execution
  - `Tooltip` component for "Why?" explanation
  - `Badge` for confidence display
  - `Button` for CTA
  - `Card` for the recommendation container

**smart-action.types.ts**:
- Export `SmartActionType = 'quick-seed' | 'clone' | 'sync' | 'none'`.
- Export `SmartActionRecommendation`:
  ```
  { action: SmartActionType; confidence: number; reason: string; reasonKey: string;
    details: { targetOrgId: string; sourceOrgId?: string; recordCounts: Record<string, number>;
    suggestedTemplate?: string; } }
  ```
- Export `OrgRecordCounts = Record<string, number>` (object API name → count).

**messages.types.ts**:
- Add `smart-action:analyze` request with `{ targetOrgId: string; sourceOrgId?: string }`.
- Add `smart-action:analyze:response` with `{ recommendation: SmartActionRecommendation }`.
- Add to message union type.

**SmartActionAnalyzer**:
- Constructor takes `deps: { getConnection: (orgId: string) => Promise<Connection> }`.
- `analyzeOrg(targetOrgId: string, sourceOrgId?: string): Promise<SmartActionRecommendation>`:
  - Query record counts on `['Account', 'Contact', 'Opportunity', 'Case', 'Lead']` for target org.
  - If sourceOrgId provided, query source org counts too.
  - Decision logic:
    - All target counts === 0 → `{ action: 'quick-seed', confidence: 0.9, reasonKey: 'home.smartAction.reasonEmpty' }`
    - Source has records, target all zero → `{ action: 'clone', confidence: 0.85, reasonKey: 'home.smartAction.reasonClone' }`
    - Both have records, no further staleness check for now → `{ action: 'sync', confidence: 0.7, reasonKey: 'home.smartAction.reasonSync' }`
    - Else → `{ action: 'none', confidence: 0, reasonKey: '' }`
  - Each query wrapped in try/catch — if an object doesn't exist (e.g., custom org without Opportunity), count = 0.
- `private queryRecordCounts(conn: Connection): Promise<OrgRecordCounts>`: parallel COUNT() queries.

**Tests**:
1. Empty target → recommends quick-seed with 0.9 confidence
2. Source populated + target empty → recommends clone
3. Both populated → recommends sync
4. Query failure on one object doesn't crash (graceful degradation)

- Uses `useBridgeQuery('smart-action:analyze', { targetOrgId })` with the first connected org as target.

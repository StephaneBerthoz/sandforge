# Plan 01: Persona Gallery UI

## Objective

Build the persona gallery for the Seed module's AI mode. Users see a card grid of 10 built-in personas (insurance, healthcare, retail, banking, SaaS, real estate, education, logistics, HR, non-profit), each with an industry icon, locale badge, and preview. Clicking "Preview" opens a popover showing 5 sample records generated client-side. Clicking "Select" opens a customization panel for adjusting field weights. A "Create Custom" card at the end enables AI-powered persona creation. SeedPage's AI mode is restructured to show a fork: "Choose a Persona" or "Start from Scratch".

## Context

- **AIPersonaManager** (`packages/extension/src/modules/ai/AIPersonaManager.ts`) already has 10 built-in personas with `getBuiltInPersonas()`, `getPersona(id)`, `createCustomPersona(description, provider)`, and `applyPersona(persona, objectName, fieldName)`. The backend is complete — this plan adds UI and bridge wiring.
- **SeedPage** (`packages/webview/src/pages/Seed/SeedPage.tsx`) has a 4-mode state: `'select' | 'ai' | 'csv' | 'clone'`. When `mode === 'ai'`, it shows TemplateGallery + SeedWizard. We restructure this: when `mode === 'ai'`, show a fork (PersonaGallery vs Start from Scratch). When user picks a persona, proceed to the wizard with pre-filled field rules.
- **TemplateGallery/TemplateCard** pattern: Responsive grid `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`, Card with CardHeader/CardBody/Badge/Button. Reuse this layout for PersonaGallery.
- **Tooltip component** exists but is text-only. For PersonaPreviewPopover, build a richer popover using absolute positioning (max-width 300px, viewport-aware flip). Use the existing DataTable component for the 5-row preview inside the popover.
- **Sample record generation**: Each persona has `dataPatterns: Record<string, PersonaFieldPattern>`. For preview, generate 5 records client-side: for each field pattern, produce a value based on `generator` type (faker → pick from `examples[]`, range → random in range, random_pick → pick from `params.values`, etc.). No API call needed.
- **Bridge messages needed**:
  - `seed:list-personas` → returns `AIPersona[]` (all built-in + custom)
  - `seed:create-persona` → `{ description: string }` → returns `AIPersona`
  - These are handled in `SeedOpsHandler.ts` using `AIPersonaManager`.
- **Lucide industry icons** (mapped by persona.industry):
  - Insurance → `Shield`, Healthcare → `Heart`, Retail → `ShoppingCart`, Banking → `Landmark`, Technology → `Cpu`, Real Estate → `Building2`, Education → `GraduationCap`, Logistics → `Truck`, Human Resources → `Users`, Non-Profit → `HandHeart`

# Plan 03: Persona Application, Adaptive Wizard & Contextual Help

## Objective

Three connected features: (1) Wire persona selection into the seed wizard so field rules are pre-filled from the persona's dataPatterns, (2) Make the AI seed wizard adaptive — auto-advance past Configure Fields for small configs (<5 objects), add grouping/search for large configs (>20 objects), (3) Add dismissible contextual help tooltips across key UI elements.

## Context

- **Persona application flow**: Plan 06-01 adds PersonaGallery and stores selected persona in SeedPage local state. This plan connects that state to the wizard. When `selectedPersona` is set, call `useSeedFieldRules.applyPersona(persona)` which iterates `persona.dataPatterns` and for each field that matches a Salesforce field in the selected objects, sets the rule type and config.
- **useSeedFieldRules** (`packages/webview/src/pages/Seed/useSeedFieldRules.ts`): Manages `fieldConfigs: ObjectFieldConfig[]`. Each ObjectFieldConfig has `fields: FieldConfig[]` with `ruleType` and `ruleConfig`. Persona application = for each selected object, for each field, check if persona has a matching `dataPatterns[fieldName]`, if so → set `ruleType` based on `generator` (faker→'faker', range→'range', random_pick→'picklist', etc.) and `ruleConfig` params.
- **Adaptive wizard**: `useSeedWizardState.ts` manages `currentStep`. For auto-advance: when user finishes step 0 (Select) and has <5 objects, call `setCurrentStep(2)` instead of `setCurrentStep(1)`. Show a subtle banner on Execute step: "Using default field rules. [Customize]" where Customize calls `setCurrentStep(1)`.
- **Large config grouping**: `Step3_ConfigureFields` renders `objectConfigs.map(...)`. For >20 objects, group by category: Standard (no `__c`), Custom (`__c`), Managed Package (`__` prefix like `ns__Object__c`). Show each group in an Accordion section. Add a search Input at the top filtering by object name.
- **InfoTooltip**: Wrap the existing `Tooltip` component. Add `(i)` circle icon (lucide `Info`). Add `id: string` prop and `dismissed` check against localStorage `sf-dismissed-tooltips` JSON array. Show small `x` button to dismiss. When dismissed, store ID in the array.
- **Tooltip placements** (initial set):
  - `help.seed.selectObjects` — on Select step header
  - `help.seed.configureFields` — on Configure step header
  - `help.seed.execute` — on Execute step header
  - `help.sync.direction` — on Sync direction selector
  - `help.clone.sourcePicker` — on Clone source picker
  - `help.home.quickActions` — on Quick Actions tile header

# Plan 04: Clone UI

## Objective

Build the complete Clone user interface: a source org picker, object selector with per-object SOQL WHERE filter, preview panel showing record counts and insertion order, execution with per-object progress tracking, and results panel with original-to-new ID mapping. Integrate into SeedPage replacing the Clone placeholder from Plan 03. This plan depends on Plan 02 (Clone backend types and handlers).

## Context

- **Clone is extension-heavy**: All heavy lifting (fetch, remap, insert) happens in the extension. The WebView only sends configuration and receives progress/results. Same pattern as existing seed execution.
- **Two-org flow**: Clone requires a SOURCE org (to query records from) and a TARGET org (to insert into). The target org is the currently selected org in useOrgStore. The source org needs a separate picker.
- **Message types from Plan 02**: `seed:clone:describe-source` (get objects from source), `seed:clone:preview` (counts + sample + order), `seed:clone:execute` (async operation with progress events).
- **Existing components to reuse**: `Select` for org/object pickers, `DataTable` for preview/results tables, `Badge` for status, `Card` for layout, `Accordion` for per-object details, `Skeleton` for loading, `Pagination` for large ID mapping tables, `OrgBadge` for org display.
- **SeedPage from Plan 03**: Plan 03 adds a mode selector to SeedPage with a Clone placeholder. This plan replaces that placeholder with the actual `CloneWizard` component.
- **useOrgStore**: Provides `orgs` (connected org list) and the currently active org. Clone source picker should show all connected orgs EXCEPT the current target org.
- **SOQL WHERE filter**: Per-object optional filter. Use a simple Input field where the user types a WHERE clause (e.g., `Industry = 'Technology' AND AnnualRevenue > 1000000`). No SOQL builder -- just raw text input with syntax hint.

**useClone** (`useClone.ts`):
- Export hook `useClone(t: TFunction)`.
- State via `useState`:
  - `sourceOrgId: string` -- selected source org.
  - `targetOrgId: string` -- from useOrgStore active org.
  - `sourceObjects: Array<{ name: string; label: string }>` -- objects available in source org.
  - `selectedObjects: CloneObjectConfig[]` -- objects selected for cloning with optional WHERE clauses.
  - `previewResult: ClonePreviewResult | null` -- from seed:clone:preview.
  - `executionStatus: 'idle' | 'previewing' | 'executing' | 'complete' | 'error'`
  - `executionResult: CloneExecutionResult | null`
  - `step: 'source' | 'objects' | 'preview' | 'execute'`
- Methods:
  - `handleSourceOrgSelected(orgId: string)`: Set sourceOrgId. Send `seed:clone:describe-source` to get objects. Store in sourceObjects.
  - `handleObjectToggle(objectApiName: string)`: Add/remove object from selectedObjects.
  - `handleWhereClauseChange(objectApiName: string, whereClause: string)`: Update WHERE clause for one object.
  - `handlePreview()`: Send `seed:clone:preview` with current config. Store result. Advance to 'preview' step.
  - `handleExecute()`: Send `seed:clone:execute`. Listen for operation:started/progress/completed/failed events. Update status and result.
  - `reset()`: Clear all state.
- Return all state + methods.

**CloneSourcePicker** (`CloneSourcePicker.tsx`):
- Export `CloneSourcePicker` functional component.
- Props: `{ sourceOrgId: string; targetOrgId: string; orgs: OrgInfo[]; onSourceSelected: (orgId: string) => void; loading?: boolean; }`.
- Show two columns side by side:
  - Left: "Source Org" -- Select dropdown with all connected orgs EXCEPT targetOrgId. Show org alias + username. Show OrgBadge for selected source.
  - Right: "Target Org" -- Read-only display of current target org with OrgBadge. Label "Records will be cloned TO this org".
- Arrow icon between the two columns indicating direction (source -> target).
- Show warning Badge if source and target are the same (should be impossible due to filtering, but defensive).
- All text via `t('seed.clone.sourcePicker.*')`.

**CloneObjectSelector** (`CloneObjectSelector.tsx`):
- Export `CloneObjectSelector` functional component.
- Props: `{ sourceObjects: Array<{ name: string; label: string }>; selectedObjects: CloneObjectConfig[]; onObjectToggle: (objectApiName: string) => void; onWhereClauseChange: (objectApiName: string, whereClause: string) => void; loading?: boolean; }`.
- Show searchable list of source objects (reuse Input for search filter).
- Each object row: checkbox + label + API name.
- When an object is checked, show an expandable section below it with:
  - Input field for optional SOQL WHERE clause.
  - Placeholder text: `e.g., Industry = 'Technology'`.
  - Help text: "Optional filter to clone only matching records".
- Show selected count Badge at top: "X objects selected".
- All text via `t('seed.clone.objectSelector.*')`.

# Plan 02: Audit & Fix All Response Type Mismatches

## Objective

Exhaustive audit and fix of every `useBridgeQuery` and `useBridgeMutation` call to ensure the `responseType` matches what the extension handler actually sends. This is the core fix that makes all modules functional.

## Context

- Research identified 1 confirmed mismatch (Settings) and 36 pending verifications
- Each hook defaults to `{requestType}:response` — if the handler sends that exact type, it works
- Some hooks override with custom `responseType` — these are the likely mismatches
- Some handlers may not exist for request types the UI sends (ghost requests)

## Strategy

For each module:
1. Read the page's data hook (useBridgeQuery/useBridgeMutation calls)
2. Read the extension handler to confirm what response type it sends
3. If mismatch → fix the hook's responseType OR the handler's response type (prefer fixing handler to match convention)
4. If handler doesn't exist → note for Plan 03 (ghost cleanup)

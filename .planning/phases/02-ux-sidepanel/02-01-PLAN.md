# Plan 1: ForgeInput UX Quick Wins

## Objective

Implement 9 UX improvements on the ForgeInput page to reduce friction in the Forge wizard. These changes make org selection smarter (auto-select, URL detection, same-org guard, swap), improve discoverability (disabled CTA hint, depth tooltips), add power-user shortcuts (Ctrl+Enter), and fix the confusing preview panel behavior for non-Record tabs.

## Context

- **ForgeInput.tsx** is at `packages/webview/src/pages/Forge/ForgeInput.tsx` (641 lines). It contains the main `ForgeInput` component and a sub-component `OrgCard`.
- **useOrgStore** exposes `selectedOrgId` (the globally selected org from SidePanel). ForgeInput currently reads `orgs` but not `selectedOrgId`.
- **SalesforceOrg.instanceUrl** contains the API endpoint (e.g., `https://na1.salesforce.com`). Lightning URLs are `*.lightning.force.com`. Domain matching must handle both formats.
- The `canDiscover` variable (line 156) controls the discover button. Currently: `hasInput() && sourceOrgId.length > 0 && targetOrgId.length > 0`.
- The swap button replaces the static `ArrowRight` icon between OrgCards (lines 222-224).
- Auto-preview fires on 400ms debounce (lines 171-180); the manual preview button (lines 285-300) is redundant.
- Existing tests are in `ForgeInput.test.tsx` (239 lines, 12 tests). The mock provides 2 orgs: `org-src` and `org-tgt`.
- Project rule: all i18n keys must be in both `en.json` and `fr.json`. Keys are nested under the `"forge"` section.
- Project rule: no `any` types, JSDoc on public methods, `t('key')` for all user-facing text.

- Add a helper function before the component (after `extractRecordId`):
  ```typescript
  /** Extract the hostname/pod from a Salesforce URL or instanceUrl. */
  function extractSalesforceDomain(url: string): string | null {
    try {
      const parsed = new URL(url);
      // Lightning: myorg.lightning.force.com -> myorg
      // Classic: na1.salesforce.com -> na1
      // Instance: https://myorg.my.salesforce.com -> myorg.my
      const host = parsed.hostname.toLowerCase();
      return host.split('.')[0] ?? null;
    } catch {
      return null;
    }
  }
  ```
- In the record input `onChange` handler (line 275), after `setRecordId(e.target.value)`, add logic:
  ```typescript
  onChange={(e) => {
    const val = e.target.value;
    setRecordId(val);
    setPreview(null);
    setPreviewError(null);
    // UX-02: Auto-detect org from pasted URL domain
    const domain = extractSalesforceDomain(val);
    if (domain) {
      const matchedOrg = orgs.find((o) => {
        const orgDomain = extractSalesforceDomain(o.instanceUrl);
        return orgDomain && orgDomain === domain;
      });
      if (matchedOrg && !sourceOrgId) {
        setSourceOrgId(matchedOrg.id);
      }
    }
  }}
  ```

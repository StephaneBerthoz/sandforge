# Plan 2: ForgeDiscovery UX — Review & Execute Label

## Objective

Rename the "Execute Forge" button in the Discovery phase to "Review & Execute". This button navigates to the `review` phase (not execution), so the current label is misleading. This is a small, surgical change to the button label and its i18n key.

## Context

- **ForgeDiscovery.tsx** is at `packages/webview/src/pages/Forge/ForgeDiscovery.tsx` (228 lines).
- The execute button is at line 217-224. It uses `t('forge.executeForge')` and calls `setPhase('review')`.
- The current i18n key `forge.executeForge` = "Execute Forge" (en.json line 1240).
- The new key `forge.reviewAndExecute` may already be added by Plan 02-01 (parallel execution). If it already exists in the JSON files, just use it. If not, add it.
- **ForgeDiscovery.test.tsx** has a test at line 156-158 that checks `setPhase('review')` is called on button click. That test does not check the label text, so it will not break.
- The `forge.executeForge` key is still used elsewhere (ForgeExecution.tsx uses it for the actual execution phase), so do NOT remove it from the i18n files.

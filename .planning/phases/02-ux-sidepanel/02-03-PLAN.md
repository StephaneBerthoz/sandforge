# Plan 3: SidePanel Refonte

## Objective

Complete refonte of the SidePanel component addressing 6 requirements: sort connected orgs first in the switcher, add compact mode for short viewports, make Quick Metrics collapsible, fix favorite star visibility, improve visual hierarchy, and remove the stale version badge from the header.

## Context

- **SidePanel.tsx** is at `packages/webview/src/SidePanel.tsx` (436 lines). It is the VSCode side panel navigation.
- The component uses `useOrgStore`, `useFavoritesStore`, and `useRecentOpsStore` for state.
- **Org switcher** (lines 136-248): Custom dropdown with org list. Currently unsorted — orgs appear in array insertion order.
- **Status dot** (lines 148-153): Shows green when `connectedCount > 0`, not based on the selected org's status. Bug: if selected org is expired but another is connected, dot shows green.
- **Quick Metrics** (lines 252-261): 2-column grid with "Orgs" and "Ops" counts. No collapse/expand.
- **Forge hero** (lines 264-289): Large gradient card (~80px height). No compact variant.
- **Favorite stars** (lines 338-349): `opacity-0 group-hover:opacity-100` makes unfavorited stars invisible until hover.
- **Version badge** (line 132): Hardcoded `v1.0` in the branding header.
- **SidePanel.test.tsx** has 14 tests. The mock provides `mockOrg` with `status: 'connected'`.
- The SidePanel is in its own webview — `window.innerHeight` reflects the actual panel height.
- Project decision: Button variant "outline" does not exist — use "secondary" instead.

**SP-01: Improved org switcher (sort connected first, accurate status)**

1. Sort orgs in the dropdown. Replace the direct `orgs.map` in the dropdown (line 188) with a sorted copy:
   ```typescript
   const sortedOrgs = useMemo(() => {
     return [...orgs].sort((a, b) => {
       // Connected orgs first
       const aConn = a.status === 'connected' ? 0 : 1;
       const bConn = b.status === 'connected' ? 0 : 1;
       if (aConn !== bConn) return aConn - bConn;
       // Then alphabetical by alias/username
       const aName = (a.alias || a.username).toLowerCase();
       const bName = (b.alias || b.username).toLowerCase();
       return aName.localeCompare(bName);
     });
   }, [orgs]);
   ```
   Add this `useMemo` after the existing derived state variables (after line 78). Import `useMemo` from React (add to the existing import at line 1).
   Then replace `orgs.map` on line 188 with `sortedOrgs.map`.

2. Fix the status dot to reflect the SELECTED org's status, not `connectedCount > 0`. In the org switcher button (lines 148-153), change:

**SP-02: Compact mode for short viewports**

1. Add a `useCompactMode` state that tracks whether the viewport is short:
   ```typescript
   const [isCompact, setIsCompact] = useState(false);

   useEffect(() => {
     const checkHeight = (): void => {
       setIsCompact(window.innerHeight < 650);
     };
     checkHeight();
     window.addEventListener('resize', checkHeight);
     return () => window.removeEventListener('resize', checkHeight);
   }, []);
   ```
   Add this after the existing state declarations (after line 79).

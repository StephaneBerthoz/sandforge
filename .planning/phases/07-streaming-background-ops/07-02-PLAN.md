# Plan 02: Background Operation Registry & Notifications

## Objective

Create the background execution infrastructure: a `BackgroundOperationRegistry` that manages detached operations (track status, emit events, abort), enhance `WebviewPanelManager` with visibility tracking, wire `activeOperations` in `WebviewStateSync`, and add VSCode native notifications for background completions.

## Context

- **Current state**: All sync/seed handlers `await` the full execution inline. The handler blocks until done. `WebviewStateSync.activeOperations` is always `[]`. No `onDidChangeViewState` listener exists. Zero VSCode native notifications in the codebase.
- **Background goal**: Handlers register the operation promise in the registry and return immediately. The registry manages lifecycle (running → completed/failed), emits events, and triggers notifications.
- **Visibility**: `retainContextWhenHidden: true` is already set (WebviewPanelManager line 81). The panel stays alive when hidden. But the extension doesn't know if it's visible.
- **Notifications**: When a panel is hidden and an operation completes, use `vscode.window.showInformationMessage()` with a "Show Details" action that reveals the panel.

## Tasks

Note: `ActiveOperation` and `BackgroundOperationStatus` types are defined in Plan 07-01 task 07-01-01 (execution.types.ts). Import them from `@sandforge/shared`.

**BackgroundOperationRegistry** — new class:

```typescript
import type { ActiveOperation, BackgroundOperationStatus } from '@sandforge/shared';

export interface RegisteredOperation {
  operationId: string;
  module: string;
  description: string;
  status: BackgroundOperationStatus;
  progressPercent: number;
  startedAt: number;
  completedAt?: number;
  resultSummary?: string;
  abortController: AbortController;
  notifiedNatively: boolean;
}

export type OperationEventType = 'started' | 'progress' | 'completed' | 'failed' | 'aborted';
export type OperationEventListener = (operationId: string, type: OperationEventType, operation: RegisteredOperation) => void;
```

**Class `BackgroundOperationRegistry`**:
- Private `operations: Map<string, RegisteredOperation>`.
- Private `listeners: Set<OperationEventListener>`.
- Private `maxCompleted: number = 50` (evict oldest completed ops when exceeded).

- **`register(operationId, module, description, promise, abortController)`**:
  1. Create `RegisteredOperation` with status `'running'`, progressPercent 0, startedAt `Date.now()`.
  2. Store in map.
  3. Emit `'started'` event.
  4. Attach `.then()` → `markCompleted(operationId)`.
  5. Attach `.catch()` → `markFailed(operationId, error)`.
  6. Return the `RegisteredOperation`.

- **`updateProgress(operationId, percent, summary?)`**:
  1. Get operation, update `progressPercent` and optional `resultSummary`.
  2. Emit `'progress'` event.

- **`abort(operationId)`**:
  1. Get operation, call `abortController.abort()`.
  2. Set status to `'aborted'`, completedAt to `Date.now()`.
  3. Emit `'aborted'` event.

- **`markCompleted(operationId, resultSummary?)`** (private):
  1. Set status `'completed'`, completedAt, resultSummary.
  2. Emit `'completed'` event.
  3. Evict oldest completed if over `maxCompleted`.

- **`markFailed(operationId, error)`** (private):
  1. Set status `'failed'`, completedAt, resultSummary from error.
  2. Emit `'failed'` event.

- **`markNotifiedNatively(operationId)`**: Set `notifiedNatively = true`.

- **`getActiveOperations(): ActiveOperation[]`**: Return all operations mapped to `ActiveOperation` shape, sorted by startedAt desc.

- **`getRunning(): RegisteredOperation[]`**: Filter by status `'running'`.

- **`has(operationId): boolean`**, **`get(operationId): RegisteredOperation | undefined`**.

- **`onEvent(listener): () => void`**: Subscribe to events. Return unsubscribe function.

- **`dispose()`**: Clear all operations and listeners.

**Tests**:
1. register() stores operation and emits 'started'
2. Promise resolution triggers markCompleted and emits 'completed'
3. Promise rejection triggers markFailed and emits 'failed'
4. abort() calls abortController.abort() and emits 'aborted'
5. updateProgress() updates percent and emits 'progress'
6. getActiveOperations() returns all ops as ActiveOperation shape
7. Evicts oldest completed when exceeding maxCompleted
8. markNotifiedNatively() sets flag correctly
</action>

1. Add private `visiblePanels = new Set<string>()` tracking which viewTypes are currently visible.
2. In `openPanel()`, after `this.broker.registerPanel(panel)`, add:
   ```typescript
   this.visiblePanels.add(config.viewType);
   panel.onDidChangeViewState((e) => {
     if (e.webviewPanel.visible) {
       this.visiblePanels.add(config.viewType);
     } else {
       this.visiblePanels.delete(config.viewType);
     }
     this.onVisibilityChange?.(this.isAnyPanelVisible());
   });
   ```
3. In `closePanel()` and `dispose()`, remove from `visiblePanels`.
4. Add method `isAnyPanelVisible(): boolean` → `this.visiblePanels.size > 0`.

3. This method will be called by the registry event listener (wired in extension.ts by Plan 07-03).

# Plan 01: Conflict Resolution Backend Wiring

## Objective

Install microdiff and build the backend infrastructure for conflict resolution: a unified UIConflict type that normalizes CDCConflict and ConflictRecord, a ConflictDiffService for structured field-level diffing with 3-way support, wired conflict feed handlers in the orchestrator, a real resolve-conflict handler replacing the NoOp stub, and extended types for baseValues and conflictCount. This plan delivers everything the UI (Plan 02) needs to display and resolve conflicts.

## Context

- **microdiff** (0.5KB, ESM-native) returns typed change descriptors with path arrays. Not yet installed. Install in `packages/shared`.
- **conflictFeedHandlers** in `RealTimeSyncOrchestrator` (line 42) is declared but never iterated -- the `onConflict` callback in CDCReplicator does not forward to these handlers. Wire it in `start()`.
- **realtime:resolve-conflict** is in `NoOpHandler.ts` (line 21) -- move to `RealTimeSyncMessageHandler` with real logic.
- **ConflictRecord** (sync.types.ts:205) lacks `baseValues` -- add optional field.
- **SyncObjectResult** (sync.types.ts:194) lacks `conflictCount` -- add it.
- **CDCConflict** (sync.types.ts:299) and **ConflictRecord** (sync.types.ts:205) are two separate types. Create a unified **UIConflict** type.
- **RealTimeConflictDetected** message type (messages.types.ts:1665) already exists with the right payload shape.
- **RealTimeResolveConflictRequest** (messages.types.ts:1578) currently has `{ eventReplayId: number; resolution: string }` -- needs extending to support per-field resolutions.
- **ConflictResolver** (ConflictResolver.ts) has 5 strategies but no `resolvePerField()` method for field-level choices.
- **SyncHistoryStore** is available from Phase 02 for logging resolution decisions.
- All i18n keys go under `sync.conflictResolution.*` namespace.

   - diffFields: handles null/undefined values correctly
   - diffThreeWay: non-overlapping changes auto-resolve
   - diffThreeWay: overlapping changes produce conflicts with baseValue
   - diffThreeWay: field changed only in source auto-resolves to source value

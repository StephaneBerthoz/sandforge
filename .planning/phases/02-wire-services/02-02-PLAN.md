# Plan 02-02: Frontend Panels (WIRE-01..05 UI side)

## Objective

Create 5 self-contained React panels that consume the bridge handler responses defined in Plan 02-01, add them to the MonitorPage layout, and write co-located tests for each. Each panel follows the established ApiUsagePanel pattern: auto-fetch via useBridgeQuery, loading/empty/data states, all text via i18n.

## Context

**Reference pattern:** `ApiUsagePanel.tsx` is the canonical example. Each panel:
1. Uses `useOrgStore(s => s.selectedOrgId)` to get the current org
2. Calls `useBridgeQuery<ResponseType>(requestType, payload, { responseType, skip: !selectedOrgId })`
3. Renders 3 states: loading (Skeleton with `data-testid="[name]-panel-loading"`), empty (`data-testid="[name]-panel-empty"`), data (`data-testid="[name]-panel"`)
4. Uses `useTranslation()` for all visible text with `t('monitor.[panel].[key]', 'fallback')` pattern
5. Wraps content in `<div className="rounded-lg border border-subtle bg-surface-1 p-4">`

**Test pattern:** `ApiUsagePanel.test.tsx` is the canonical example. Each test file:
1. Mocks `useBridgeQuery` at module level via `vi.mock('../../hooks/useBridgeQuery', ...)`
2. Uses `let mockData` / `let mockLoading` variables to control state per test
3. Sets `useOrgStore.setState({ selectedOrgId: 'org-1', orgs: [] })` in `beforeEach`
4. Tests: loading state, empty state, data state (minimum 3)
5. Imports `'../../i18n'` for translation initialization

**Message types from Plan 02-01:**
- `monitor:error-logs` -> `monitor:error-logs:response` (payload: `{ success, errors, errorsByType, totalCount }`)
- `monitor:sessions` -> `monitor:sessions:response` (payload: `{ success, sessions, activeUserCount }`)
- `monitor:apex-insights` -> `monitor:apex-insights:response` (payload: `{ success, analyses, topIssues }`)
- `monitor:sandbox-refresh` -> `monitor:sandbox-refresh:response` (payload: `{ success, refreshes, inProgress }`)
- HealthCheckPanel reads from the existing `monitor:data` response which now includes `orgHealthStatus`

**i18n keys available (from Plan 02-01):** All keys are under `monitor.*` namespace with panels: `errorLogs`, `sessions`, `apexInsights`, `sandboxRefresh`, `healthCheck`.

**MonitorPage integration:** New panels are dropped into `MonitorPage.tsx` as standalone components (no props). They go after the existing `<DeploymentTimeline />` and before the anomaly results section. All 5 panels read `selectedOrgId` internally.

**UI components available:** `Skeleton`, `Badge`, `ProgressBar`, `Button`, `Spinner` from `../../components/ui/`. Icons from `lucide-react`. `formatNumber` from `../../utils/formatters`.

Helper function to map status to badge variant:
```typescript
function statusVariant(status: 'ok' | 'warning' | 'critical' | 'healthy' | 'degraded'): BadgeVariant {
  switch (status) {
    case 'ok':
    case 'healthy': return 'success';
    case 'warning':
    case 'degraded': return 'warning';
    case 'critical': return 'error';
    default: return 'default';
  }
}
```

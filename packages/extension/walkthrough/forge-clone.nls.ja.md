## Forge でデータをクローン

実際のレコードから開発サンドボックスにデータを投入します。

1. UAT 組織のルートレコード ID を **レコードIDまたはSalesforce URL** に貼り付けます — 取引先が扱いやすい例です。
2. **グラフを検出** をクリックすると、Forge がレコードのリレーションシップグラフ（取引先責任者、商談、ケース…）をたどります。
3. **深さ**、**オブジェクトごとのレコード数**、**PIIを匿名化** を調整します。
4. 開発サンドボックスに向けて **確認して実行** をクリックします。書き込み時に ID は再マッピングされますが、同じ API 参照名の有効なレコードタイプがターゲットにない場合、そのレコードタイプはソースの Id のまま残り、SandForge のログに記録されます。

[Forge を開く](command:sandforge.openForge)

## Forge でデータをクローン

実際のレコードとそれにつながるレコードを、別の組織から投入先の組織へコピーします。

1. 2 つの組織を接続します。コピー元の組織（UAT Sandbox など）と、投入先の組織です。サイドパネルで選択中の組織が **ソース組織** になります。
2. 投入先の組織を **ターゲット組織** で選択します。選択するまで **グラフを検出** は押せません。
3. レコードの ID または URL を **レコード ID または Salesforce URL** に貼り付けます — 取引先が扱いやすい例です。**深さ**（最大 **深い（5 レベル）**）、**オブジェクトごとのレコード数**、**PII を匿名化** はボタンの上にあります。検出で読む範囲を決めるので、ここで設定してください。最後の深さ **ALL** は、代わりにソース組織全体をコピーします。貼り付けるレコードは不要で、オブジェクトごとの上限もありません。
4. **グラフを検出** をクリックし、続けて **確認して実行** をクリックします。
5. 確認画面で、**シミュレーション** はすべてのレコードを確認し、何も送信しません。**リハーサル** はターゲットにサンプルを試させてロールバックし、API コールを消費します。**Forge を実行** で書き込みます。結果画面または **最近の実行** の **この実行が作成したレコードを削除** で、実行を取り消せます。組織全体のクローン (**ALL**) では、**シミュレーション** も **リハーサル** もまだ使えません。**Forge を実行** が書き込みの前に必ず求める確認に、書き込む内容が表示されます。

お急ぎですか？ **グラフを検出** の下の **直接クローン** は、検出が応答するとすぐにクローンを開始し、グラフや確認画面では止まりません。このとき 2 つの組織間のメタデータ比較は実行されません。25 を超えるオブジェクトのグラフは、描く代わりにテーブルに一覧表示されます。**グラフビュー** / **テーブルビュー** の切り替えと `sandforge.forge.graphView` 設定で選べます。
